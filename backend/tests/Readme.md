# Recipes API Тесты

Это набор тестов для API рецептов на Django REST Framework.  
Тесты разделены по функциональным модулям:

- `test_recipes.py` — тесты работы с рецептами: создание, получение, валидация, изображения, дубликаты.
- `test_favorites.py` — тесты функционала избранного (favorites), например, добавление и удаление рецептов из избранного.
- `test_subscriptions.py` — тесты подписок на авторов рецептов: создание, получение списка подписок и отписка.
- `test_users.py` — тесты регистрации, аутентификации и работы с пользователями.

## Основные возможности тестов

- Проверка работы CRUD операций с рецептами.
- Валидация данных рецептов (теги, ингредиенты, время приготовления).
- Работа с изображениями в формате base64.
- Проверка ограничения доступа для неавторизованных пользователей.
- Тестирование функционала избранного и подписок.
- Проверка авторизации и управления пользователями.

## Запуск тестов

Убедитесь, что у вас настроена среда Django и установлены зависимости (pytest, pytest-django и др.).
